# Project Visualizations

This directory contains the original graphical outputs extracted from the completed Diabetes Prediction Using KNN notebook.

## Visualization Index

| Visualization | Description |
|---|---|
| baseline_confusion_matrix.png | Classification performance of the baseline KNN model |
| cross_validation_comparison.png | Cross-validation performance of all four model versions |
| model_performance_comparison.png | Baseline and final optimized model testing performance |
| false_negative_comparison.png | Comparative false-negative and false-positive analysis |
| roc_curve_comparison.png | ROC curves of all four KNN model versions |
| final_interactive_prediction.png | Final optimized model prediction demonstration |
| interactive_prediction_comparison.png | Baseline and optimized prediction probability comparison |
| smote_class_distribution.png | Training class distribution before and after full SMOTE balancing |
| confusion_matrix_comparison.png | Comparative confusion matrices of all four models |
| model_improvement_journey.png | Evolution of cross-validation recall and F1-score |
| feature_correlation_heatmap.png | Correlation analysis of dataset features |

## Visualization Methodology

All visualizations were generated using Matplotlib and Seaborn during the original machine learning experiments.

The PNG images were extracted directly from the saved notebook outputs without modifying their numerical results or graphical content.

## Disclaimer

The interactive prediction graphs represent educational model demonstrations. Estimated class probabilities are not calibrated clinical risk estimates.
