# Project Notebooks

This directory contains the two primary Google Colab notebooks used in the project.

## 01_Diabetes_Prediction_KNN_Baseline.ipynb

Initial KNN model implementation, data preprocessing, exploratory data analysis, baseline performance evaluation and interactive prediction.

## 02_Diabetes_Prediction_KNN_Optimization.ipynb

Complete model development, hyperparameter optimization, SMOTE class balancing, advanced preprocessing, comparative evaluation, final model selection and interactive prediction system.
