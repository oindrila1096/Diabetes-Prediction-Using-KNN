# Experimental Results

This directory contains the exported results obtained during model development, optimization, comparative evaluation and interactive prediction testing.

| File | Description |
|---|---|
| cross_validation_comparison.csv | Cross-validation performance of all four model versions |
| testing_performance_comparison.csv | Training and testing performance comparison |
| classification_error_analysis.csv | False-negative and false-positive analysis |
| final_model_improvements.csv | Absolute and relative performance changes |
| generalization_analysis.csv | Training, cross-validation and testing performance gaps |
| package_versions.csv | Recorded Python package versions |
| sample_prediction_comparison.csv | Baseline and optimized predictions for synthetic inputs |
| prediction_system_verification.csv | Prediction consistency verification results |

All exported results were generated from the project notebooks.
